# 12-质量门禁与复查清单

## 1. 覆盖率检查
- 源码文件、资源文件、协议文档均已分层讲解，未遗漏主链路与关键组件。
- 每章节均附证据链，便于定位源码与文档出处。

## 2. 证据链检查
- 随机抽样 10 条结论，均能定位到具体文件与符号。
- 章节内所有关键结论均有文件路径与类/方法名佐证。

## 3. 教学有效性检查
- 每批讲解均产出 3 个以上真实 Kotlin/Android 知识点实例。
- 术语表、路线图、易错点、排错建议均已覆盖。

## 4. 一致性检查
- 架构图、生命周期链路、文件讲解和协议说明无冲突。
- 章节间术语、分层、主链路描述一致。

## 5. 运行语义检查
- 权限依赖、前台服务保活、反向连接约束等关键运行语义均有专节讲解。
- 结合协议与源码，确保描述与实际行为一致。
